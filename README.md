## 🚀 Cómo ejecutar un proyecto

1. Clona este repositorio:
   ```bash
   git clone https://github.com/Adri-Coding-Dev/Mis_Proyectos_en_RUST.git
   cd Mis_Proyectos_en_RUST
   ```

2. Entra en la carpeta del proyecto que quieras probar:
   ```bash
   cd 02_adivina_numero
   ```

3. Compila y ejecuta con Cargo:
   ```bash
   cargo run
   ```

Asegúrate de tener Rust instalado. Si no, sigue las instrucciones en [rustup.rs](https://rustup.rs/).
